# Jugaad Fluency v3

Reels jaisi English speaking practice. Feed mein upar swipe karo, har card 30–60 second ka hai.

Card types: Naya word, Bolne wala phrase, Shadowing, Hindi se English, Sahi ya galat, Yaad hai? (spaced repetition), 60-sec Non-stop challenge (4/3/2 drill), Roleplay.

## Files
- `index.html`: poora app
- `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`: home-screen app (PWA) ke liye

## AI
Me → AI settings mein Gemini (Google AI Studio) ya Groq key daalo, ya laptop par Ollama chalao.
Key kabhi is repo ke code mein mat likhna.

Ollama ke liye laptop par chalao: `OLLAMA_ORIGINS="https://<username>.github.io" ollama serve`
